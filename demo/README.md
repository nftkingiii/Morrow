# Morrow demo video

The submission video is a prerecorded product explainer generated from:

- captures of the public Railway application;
- verified Starknet Mainnet transaction evidence;
- purpose-built motion cards that explain the public/private boundary; and
- synthetic narration, so no presenter recording is required; and
- 33 burned-in, two-line caption blocks for reliable playback on any host.

It does not present a reconstructed wallet interaction as a live transaction. The full narration is in `narration.json`; `captions.srt` contains the timed caption source; `storyboard.html` contains the visual scenes; and `render-demo.ps1` renders the reproducible 1080p source.

The published artifact is copied to `public/morrow-demo.mp4` and declared in root `strk20.json`.
